Standalone Lightweight Portal Clean Architecture

Infrastructure Automation Portal

Simple, self-contained architecture for SAP & Oracle infrastructure operations with single designated approver gate and direct GitHub Actions execution.

⚡ The 4-Tier Architecture Blueprint

The portal connects four streamlined components with zero external infrastructure overhead:

Tier 1: Frontend UI
React 18 & Vite
Clean Single Page App providing Dashboard, Catalogue selection, Approvals Workbench, and Executions History. Includes built-in role switcher.
Port 5173 • frontend/
Tier 2: Backend API
FastAPI Gateway
REST API validating incoming requests, enforcing the single designated approver gate, and dispatching execution workflows.
Port 8000 • backend/main.py
Tier 3: Local Storage
SQLite Database
Zero-setup single file database storing automation requests, executions, and audit records with automatic table initialization.
backend/portal.db
Tier 4: Execution Engine
GitHub Actions
Dispatches workflow_dispatch events to run your existing Ansible playbooks in CI/CD. Includes realistic simulation fallback for demos.
backend/github_service.py

📂 Component & File Directory Map

Clean breakdown of the codebase files and their exact role:

Backend (`backend/`)

backend/main.py
FastAPI entrypoint, REST API endpoints, CORS config, and startup database bootstrap.
backend/database.py
SQLite connection factory, automatic table schema creator, and tamper-evident audit logger.
backend/auth.py
Extracts user from X-Portal-User header and enforces designated approver authorization (HTTP 403 guard).
backend/github_service.py
Dispatches GitHub Actions workflow_dispatch API via HTTPX (with realistic demo simulation fallback).
backend/automations.json
Predefined catalogue file holding the 10 SAP & Oracle automations with input parameter mappings.
backend/portal.db
Single-file SQLite database storing requests, executions, users, and audit trail logs.

Frontend (`frontend/src/`)

frontend/src/App.tsx
Root React router layout, sidebar navigation, and active role switcher state management.
frontend/src/pages/Catalogue.tsx
Catalogue card grid with category/OS filters and request launch buttons.
frontend/src/pages/Approvals.tsx
Approval Workbench with role-guard notice and 1-click Approve / Reject decision modals.
frontend/src/pages/Executions.tsx
Execution tracking monitor with live status badges, terminal log viewer, and GitHub status sync.
frontend/src/components/RequestModal.tsx
Form modal enforcing mandatory SID validation and parameter collection.
frontend/src/api.ts
Axios API client automatically attaching active user role header to every outgoing HTTP call.
