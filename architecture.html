Infrastructure Automation Portal

Simple, independent, lightweight infrastructure portal. Contains strictly the simplified self-service code with all ITSM dependencies removed.

⚡ Pure Standalone Version (Zero ITSM Overhead)

This branch represents a clean, independent deployment of the Infrastructure Automation Portal. All legacy ITSM platform modules (RabbitMQ message queues, PostgreSQL clusters, dead-letter exchanges, BMC Helix/ServiceNow webhooks, and complex incident/change ticket lifecycles) have been completely removed. The codebase consists strictly of: Frontend (React + Vite) → Backend (FastAPI) → SQLite (portal.db) → GitHub Actions (HTTPX).

2 What Was Removed vs. Retained in This Branch

❌ Completely Removed (No ITSM Overhead)
  • 🗑️ No RabbitMQ: No message brokers, queues, exchanges, or dead-letter queues.
  • 🗑️ No PostgreSQL: No external database servers or connection pooling.
  • 🗑️ No ITSM Tickets: No Incident, Service Request, or Change Request lifecycles.
  • 🗑️ No ServiceNow/Helix: No enterprise ticket synchronization or webhook mocks.
  • 🗑️ No Local Host Ansible: No direct shell playbook runs on the local server.
✅ Retained & Streamlined (Simple & Direct)
  • ✨ Direct 4-Step User Journey: Select → Input SID → Approve → Dispatch.
  • ✨ Embedded SQLite: Single file persistence (portal.db) with automatic schema initialization.
  • ✨ Single Designated Approver Gate: Protects against accidental production restart or stop operations.
  • ✨ Configuration-Driven: 10 predefined SAP & Oracle automations in automations.json.
  • ✨ Direct CI/CD Integration: Triggers existing GitHub workflows via clean HTTPX client.
